# Equipo IA 4.3.2

Corrige una aprobación incorrecta cuando la línea base y el parche producen el
mismo fallo genérico del proceso de pruebas. Ese resultado no demuestra que las
pruebas individuales sigan igual: ahora requiere `REVISION_MANUAL`.

- Se comprueba la integridad de los informes TAP y pytest antes de comparar
  fallos heredados con los actuales y los del control.
- `/aplicar` exige evidencia de comparabilidad si las pruebas siguen en rojo.
- Se conservan los casos válidos de base roja sin regresiones y de reparación
  completa de las pruebas.
- Se añaden pruebas de regresión y se actualiza la documentación.

Validación local: 84 comprobaciones aprobadas, demo `VALIDADO`, sintaxis Bash
correcta, ShellCheck (`-S error`) sin errores y escaneo básico de secretos sin
coincidencias. Las pruebas usan
agentes simulados y no requieren claves ni llamadas a modelos.

Para actualizar una instalación existente, ejecuta `./install.sh` desde esta
versión del repositorio y comprueba `equipo --version`. La configuración del
usuario se conserva. Repite las ejecuciones antiguas con base roja antes de
aplicar sus parches: pueden carecer de la nueva evidencia requerida.

La comparación sigue siendo heurística y no sustituye la revisión humana.
Los informes ambiguos o incompletos requieren revisión manual.
