# Equipo IA 4.5.0 — interfaz para Windows

Esta versión incorpora una ventana para preparar el entorno, trabajar con un
proyecto Git, revisar propuestas y aplicar y guardar los cambios. Conserva los
comandos de publicación de la consola añadidos en 4.4.0.

## Descargar y abrir en Windows

1. Descarga `Equipo-IA-Windows-v4.5.0.zip` de los archivos del release.
2. Extrae toda la carpeta `Equipo-IA`.
3. Abre `windows/Instalar Equipo IA.cmd` y después el acceso directo del escritorio.
4. En Preparación, selecciona o prepara Ubuntu/WSL y conecta tu cuenta para tareas
   reales. Puedes probar el ejemplo simulado sin una cuenta de IA.

La ventana permite elegir el proyecto y los agentes, pedir cambios, consultar
parches, revisiones e informes, aplicar una propuesta validada y guardar un commit
local. El historial conserva las tareas y permite recuperar sus resultados.

## Requisitos y alcance

Se utiliza Windows PowerShell 5.1 y Windows Forms; el motor y los agentes corren
en Ubuntu/WSL. El ZIP incluye un instalador por usuario y no es un `.exe` firmado.
Cada persona conecta sus propias cuentas. La ventana guarda commits locales;
`/publicar` sigue disponible desde la consola para subirlos a un remoto Git.

El mantenedor informó haber probado la aplicación en su computadora Windows.
Se distribuye como vista previa: el detalle de esa prueba y la lista completa
de aceptación aún no están documentados. Consulta [la guía](../windows.md).

## Comprobaciones

- Pruebas del motor, publicación y puente Windows con agentes simulados en Linux.
- Comprobaciones de argumentos, sintaxis y construcción de la ventana en el CI
  de Windows; el script de entrega exige que termine correctamente antes de crear
  el release.
- El paquete incluye el motor 4.5.0 y sus archivos de publicación. Conserva BOM
  UTF-8 y finales CRLF en PowerShell, y finales LF en Bash.

La política de revisión y validación del motor se mantiene. La guía explica los
límites actuales y las comprobaciones manuales para otros equipos Windows.
