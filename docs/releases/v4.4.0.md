# Equipo IA 4.4.0 — publicación de proyectos

La consola ahora permite subir una versión guardada del proyecto a su repositorio
Git mediante `/publicar`, después de ejecutar las pruebas y confirmar el destino.

## Novedades

- `/publicar` muestra proyecto, commit, URL y rama; ejecuta las pruebas y pide
  escribir `PUBLICAR` antes de enviar el commit.
- `/publicar comprobar` verifica el destino local y las pruebas sin enviar cambios.
- Se usa la rama upstream o, si no existe, `origin` con el mismo nombre de rama.
- Se guardan informes con commit, destino, pruebas y resultado del envío.
- Se rechazan cambios pendientes, HEAD separado, pruebas fallidas, destinos
  múltiples o cambios del commit, rama o destino durante la comprobación.
- Los comandos desconocidos que empiezan por `/` muestran ayuda en vez de
  enviarse al agente programador.

## Actualización

Descarga y extrae el paquete, ejecuta `./install.sh` y vuelve a abrir `equipo`.
La configuración personal se conserva. Dentro de tu proyecto, guarda los cambios
revisados con Git y ejecuta `/publicar`.

## Alcance y validación

La política de validación de parches se mantiene. Publicar exige pruebas verdes
en la versión actual, aunque el parche se validara contra una base con fallos.
El comando no fuerza pushes ni publica otras ramas o etiquetas. Publica código;
el despliegue web requiere un hosting o workflow configurado por separado.

La entrega incluye 84 comprobaciones del motor y 15 pruebas de publicación con
remotos Git locales, sin cuentas ni red. Incluyen instalación, rechazo de envíos
divergentes, cancelación, destinos, cambios durante las pruebas y comandos de
consola. Se comprueban también sintaxis Bash, ShellCheck y la demo.
