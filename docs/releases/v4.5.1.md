# Equipo IA 4.5.1 — corrección del test de Windows

El CI de 4.5.0 se detuvo en la comprobación de argumentos: Windows PowerShell 5.1
entrega un array JSON como un solo objeto y la prueba añadía otro nivel de array
al recogerlo. Esto producía el mensaje «Se perdieron argumentos».

La respuesta de Python ahora usa un objeto con la propiedad `arguments`. El test
compara su contenido con cada argumento original, incluidos vacíos, comillas,
barras, Unicode y saltos de línea. Se añaden casos de cero y un argumento. El
transporte de la aplicación y sus comprobaciones de seguridad se mantienen.
La construcción real de la ventana WinForms continúa siendo parte obligatoria
del CI. [Referencia del comportamiento de PowerShell](https://github.com/PowerShell/PowerShell/issues/3424).

## Instalar en Windows

Descarga `Equipo-IA-Windows-v4.5.1.zip`, extrae toda la carpeta y abre
`windows/Instalar Equipo IA.cmd`. Conserva la interfaz y las funciones incluidas
en 4.5.0. La interfaz Windows se distribuye como vista previa.

El release se crea únicamente después de que los trabajos de Linux y Windows del
commit corregido terminen correctamente. La etiqueta anterior `v4.5.0` se conserva.
