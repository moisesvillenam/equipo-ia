# Código de conducta

## Nuestro compromiso

Este proyecto busca un espacio respetuoso, técnico y acogedor para personas de
cualquier experiencia, origen e identidad. Se valora la crítica concreta y la
evidencia; no los ataques personales.

## Comportamiento esperado

- Sé respetuoso y específico.
- Critica ideas y código, no personas.
- Explica el contexto y ofrece alternativas.
- Acepta que una revisión pueda pedir más pruebas o más evidencia.
- No publiques datos privados, credenciales ni información de terceros.

## Comportamiento inaceptable

- Acoso, insultos, discriminación o amenazas.
- Publicar información privada sin permiso.
- Spam, promoción no solicitada o manipulación de discusiones.
- Introducir código malicioso o debilitar las comprobaciones de seguridad.

## Aplicación

Los mantenedores pueden editar, cerrar o eliminar contribuciones que incumplan
estas normas. Para reportar un incidente, usa un canal privado del repositorio
(Security Advisories o el contacto que indiquen los mantenedores). No se incluye
un correo personal en este repositorio.

Este código se inspira en prácticas habituales de proyectos open source; no es
una adaptación literal de un texto concreto.
